This repository contains my work for the Diwali Independent Learning Assignment (**The Digital Detective**). The goal of this assignment is to explore how my computer works, practice using the Terminal, understand operating systems and program execution, build a small Python number converter, use Git and GitHub, and learn basic computer networking.

Each mission was completed, documented in its own `README.md`, and committed separately in order.

## Topics Explored
- Computer fundamentals and the IPOS model (Input, Processing, Output, Storage)
- Terminal commands, file management, flags, pipes, and package managers
- Operating system details, processes (PIDs), paths, and file permissions
- Running Python programs and comparing compilers vs. interpreters
- Binary/hexadecimal conversions, text encoding (ASCII and UTF-8), and a Python converter
- Git workflow, branches, and Pull Requests on GitHub
- Networking basics (LAN, MAN, WAN, DNS, routers, protocols, packet switching, client-server)

## How to Run the Number Converter
From the repository root, move into the Mission 5 folder and run `number_converter.py` with Python 3:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any positive decimal number when prompted, and it will print the binary and hexadecimal values.
