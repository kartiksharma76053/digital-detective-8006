### Task 1.1 — Trace one activity using IPOS
**Activity:** Typing and saving a short Python script in VS Code.

| Stage | What happens in my example? | Possible hardware / component |
| :--- | :--- | :--- |
| Input | I press keys on the keyboard to type the Python code and click Save with the trackpad. | Keyboard, trackpad |
| Processing | The processor reads the key presses, runs the editor, and prepares the text to be displayed and saved. | CPU / processor, RAM (memory) |
| Output | The typed characters and syntax colors appear on the laptop screen so I can see my code. | Laptop screen (display) |
| Storage | When I press Command + S, the file is written to the laptop's SSD so it stays saved even after turning off the laptop. | SSD (Solid State Drive) |

**How the activity moves:** When I type, the keyboard sends signals to the CPU, which holds the text in RAM and updates the screen right away (output). When I save, the CPU writes that data from RAM onto the SSD (storage) so it is not lost.

## 4. My understanding
Every computer task follows the IPOS cycle. Input devices bring data in, the CPU and RAM process it, output devices show the result, and storage saves it for later. Hardware is the physical part I can touch, while software is the set of programs running on it—divided into operating systems, apps for everyday tasks, and utilities for managing the computer. Even machines like ATMs and ticket kiosks are computers following the same IPOS idea.
